# Order of Complexity

## Matrix Multiplication

- Two matrix having size of $ n \times n $ and $ n \times n $ will have order of $ \large{O}\normalsize{(n^3)} $.
- Two matrix having size of $ a \times b $ and $ b \times c $ will have order of $ \large{O}\normalsize{(a\cdot b\cdot c)} $.
- Linear equation with $ n $-variables - $ \large{O}\normalsize{(n^2)} $.
- Find a number in a unsorted list: $ \large{O}\normalsize{(n)} $
- Binary search tree: $ \large{O}\normalsize{(log(n))} $
- Your own sorting algorithm i.e. Bubble sort: $ \large{O}\normalsize{(n^2)} $
- Check method of our decision tree: $ \large{O}\normalsize{(n^2)} $
